# 前端修改说明

## 📋 修改概述

根据后端架构调整（统计数据走Redis，明细数据走MySQL），对前端直播任务页面进行了相应优化，主要增加了聊天数据的模糊查询功能。

## ✅ 修改内容

### 1. 数据结构调整 (`src/views/live/task/index.vue`)

#### 新增搜索条件字段
在 `detailDialog` 中添加了 `chatSearch` 对象：

```javascript
chatSearch: {
    userNickname: '',  // 用户昵称搜索
    content: ''        // 聊天内容搜索
}
```

### 2. UI界面增强

#### 聊天Tab添加搜索栏
在详情弹窗的聊天数据Tab顶部添加了搜索区域：

- **用户昵称输入框**：支持按用户昵称模糊搜索
- **聊天内容输入框**：支持按聊天内容模糊搜索  
- **搜索按钮**：触发搜索操作
- **重置按钮**：清空搜索条件并重置到第一页

样式特点：
- 浅灰色背景 (#f5f7fa)
- 圆角边框 (4px)
- Flexbox布局，元素居中对齐

### 3. 方法实现

#### 新增方法

**onChatSearch()** - 搜索方法
```javascript
onChatSearch() {
    // 重置到第一页
    this.state.detailDialog.chatPage = 1;
    this.fetchDetailTabData();
}
```

**onChatSearchReset()** - 重置方法
```javascript
onChatSearchReset() {
    // 清空搜索条件
    this.state.detailDialog.chatSearch.userNickname = '';
    this.state.detailDialog.chatSearch.content = '';
    // 重置到第一页
    this.state.detailDialog.chatPage = 1;
    this.fetchDetailTabData();
}
```

#### 修改方法

**fetchDetailTabData()** - 增加搜索参数传递
```javascript
// 构建查询参数
const params = {taskId, page, size: 5};

// 如果是聊天数据，添加搜索条件
if (tab === 'chat') {
    if (this.state.detailDialog.chatSearch.userNickname) {
        params.userNickname = this.state.detailDialog.chatSearch.userNickname;
    }
    if (this.state.detailDialog.chatSearch.content) {
        params.content = this.state.detailDialog.chatSearch.content;
    }
}

apiMethod(params).then(response => {
    // ... 处理响应
});
```

**onViewDetail()** - 查看详情时重置搜索
```javascript
// 重置搜索条件
this.state.detailDialog.chatSearch.userNickname = '';
this.state.detailDialog.chatSearch.content = '';
```

3. **组合搜索**：可同时使用多个条件进行筛选

- ✅ 打开详情弹窗时自动重置搜索

### 数据查询
- ✅ 直接查询MySQL数据库（不走缓存）
- ✅ 支持分页查询
- ✅ 保留原有5条/页的显示设置
- ✅ 与后端API完美对接

## 📊 数据流

```
用户输入搜索条件
    ↓
点击"搜索"按钮
    ↓
调用 onChatSearch()
    ↓
重置页码到第1页
    ↓
调用 fetchDetailTabData()
    ↓
构建查询参数（包含userNickname和content）
    ↓
调用 API: chatList({taskId, page, size, userNickname, content})
    ↓
后端查询MySQL数据库
    ↓
返回符合条件的数据
    ↓
更新表格显示
```

## 🔧 技术要点

### Vue 2 响应式
- 使用 `v-model` 双向绑定搜索条件
- 利用 Element UI 的 `clearable` 属性
- 通过 `@click` 事件触发搜索

### 参数传递
- 仅在聊天Tab时添加搜索参数
- 空值不传递（避免影响后端查询）
- 保持与其他Tab的兼容性

### 分页联动
- 搜索时自动重置到第一页
- 翻页时保持搜索条件不变
- 重置时同时清空条件和页码

## ⚠️ 注意事项

1. **后端依赖**：需要后端 `LiveDataPageQuery` 支持 `content` 字段
2. **性能考虑**：模糊查询可能较慢，建议合理设置分页大小
3. **数据实时性**：直接从MySQL查询，数据可能有5-10秒延迟（批量写入间隔）
4. **浏览器兼容**：使用现代CSS特性，建议在Chrome/Firefox等现代浏览器使用
